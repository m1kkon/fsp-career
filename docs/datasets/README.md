# Датасеты для обучения подбора

Исследование 8–9 октября 2026: какие открытые данные подходят для обучения и проверки модели подбора кандидатов под потребность работодателя. Нужны реальные IT-данные, где есть вакансия, кандидат и взаимодействие между ними (отклик, приглашение, отказ), а тексты похожи на анкеты и запросы ФСП Карьеры.

## Главное

| Набор | Тексты кандидата | Тексты вакансии | Взаимодействие | IT-пар |
|---|---|---|---|---|
| «Работа России», открытые данные (opendata.trudvsem.ru) | должность, навыки, опыт с описанием, зарплата | обязанности, требования, навыки, зарплата | отказ, приглашение, принятие | ~3,6 тыс. с исходом (~95% отказы) + ~10 тыс. откликов без реакции по трём снапшотам; за 2 года ≈ 9–14 тыс. реакций (оценка) |
| ML TalentMatch 2024 | полные резюме: «о себе», опыт, навыки | полные описания | confirmed / failed | 656 (100% IT); уже используется в [benchmark](../matching-benchmark.md) |
| hh.ru, олимпиада ВШЭ DANO 2023–24 | только структура: навыки, опыт, зарплата, формат | только структура | отклик → приглашение / отказ | ~23 тыс. |
| Rabota.ru, тестовое задание | должность и структура | полное описание | отклик, приглашение | мало, в основном не IT |

Открытого набора, где IT-резюме уровня наших анкет связаны с откликами в десятках тысяч пар, нет. Практичная связка: «Работа России» для обучения на реальных решениях работодателей, DANO для структурных признаков, ML TalentMatch для оценки, а дальше — собственные логи приглашений и откликов, собранные с согласия.

## Как повторить подсчёт по «Работе России»

Скрипты читают официальные выгрузки потоком и сохраняют только ID, перечисления и даты; персональные данные на диск не пишутся. Запускайте из папки `trudvsem/`:

```sh
curl -s <XML откликов> | python3 parse_inter.py response
curl -s <XML приглашений> | python3 parse_inter.py invitation
curl -s https://opendata.trudvsem.ru/json/vacancy.json | python3 parse_json.py vac vac_all_part1
python3 sample_cv.py 120 4000000 1
python3 join.py
```

Ссылки на текущие XML откликов и приглашений даны в `meta.csv` наборов `7710538364-response` и `7710538364-invitation`. `join.py` дополнительно читает снапшоты вакансий `vac_s*_all.tsv.gz`, разобранные тем же `parse_json.py vac`. Региональные XML-снапшоты разбирает `parse_vacxml2.py`; их подключение, давшее покрытие 48,8% откликов, описано в [заметках](notes/trudvsem-it-pairs.md) и выполнялось отдельным шагом. `classify.py` относит вакансию или резюме к ядру IT, 1С и смежным ролям; `fetch_ranges.py` докачивает большие файлы по HTTP Range. Сводки `*_stats.json`, `inter_summary.json` и `join_summary.json` — результаты прогона 8–9 октября 2026.

Выгрузки «Работы России» содержат персональные данные, несмотря на описание наборов. Сырые записи нельзя публиковать и хранить вне России; для обучения их нужно обезличить (подробнее — в отчётах).
