Четыре шага, соединённые как узлы сети из нашего знака. Кандидат заполняет анкету и подтверждает категорию тестом. Компания описывает задачу своими словами. Система показывает подборку, где у каждого балла есть основание. Последний узел — красная точка, та самая возможность: приглашение с зарплатой.
