Кандидату

Предложения приходят сами

Категория подтверждена тестом

Зарплата видна сразу

Контакт — только с вашего согласия

05

Кандидат один раз заполняет анкету и резюме, проходит тест по своей роли и дальше получает приглашения. В каждом приглашении видна зарплатная вилка. Контакт открывается только той компании, которой кандидат согласился его показать. На экране — реальная карточка приглашения из продукта.
