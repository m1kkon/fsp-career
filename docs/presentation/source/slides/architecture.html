Модульный монолит: Next.js и Node.js держат API и всю бизнес-логику на сервере, данные — в PostgreSQL с транзакциями. Код кандидатов исполняется в Docker-песочнице без сети, с лимитами памяти и времени. Пароли хешируются scrypt, сессии — HttpOnly-cookie, в базе хранится только хеш токена, очередь писем зашифрована; контакт кандидата виден только компании, которой он дал согласие. Каждый пуш в main проходит 377 автотестов с PostgreSQL и автоматически деплоится на GCP.
