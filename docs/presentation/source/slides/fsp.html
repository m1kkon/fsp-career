ФСП — сильный сигнал, но не фильтр. Привязка ФСП ID подтягивает историю соревнований; учитываются уровень лучшего результата, профильность дисциплины и давность — до 6 баллов внутри уже подтверждённой категории. Кандидат без олимпиадного опыта ничего не теряет, а скрытую историю рейтинг не учитывает. Сейчас работает тестовый адаптер, реальный реестр подключается после согласования API с ФСП.
