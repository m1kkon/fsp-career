## Обновление документации

После изменения поведения синхронизируйте тематический документ, README и затронутые контракты API. Для публичной OpenAPI используйте `node scripts/generate-public-api.mjs` и тест актуальности. При изменении правил оценивания записывайте новую версию; не переписывайте результаты старого эксперимента. Указывайте источник данных, дату, пропуски и ограничения проверок. Публикация документации не подтверждает деплой: сверяйте SHA в `/api/health`.

Оригинальные документы заказчика, сторонние лицензии, сохранённые измерения и их хеши не редактируются для согласования с новой реализацией. Новый вывод или эксперимент оформляется отдельно.
