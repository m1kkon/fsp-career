# Суточные пулы вопросов

Кандидат выбирает навык или роль и сразу открывает страницу начала теста. Календаря и предварительной записи нет. Для роли грейд выбирается на этой странице. Попытка и первый таймер создаются только после нажатия «Начать тест» и принятия правил.

Общий пул действует ровно 24 часа: с 00:00 до 00:00 по Москве (UTC+3). Его ID содержит дату. Серверный планировщик создаёт текущий пул при запуске приложения и следующий в полночь. Если приложение было выключено или создание не удалось, подготовка/запуск теста создаст недостающий текущий пул. При ошибке планировщик повторяет попытку через минуту.

Пул содержит сохранённые экземпляры вопросов для всех 18 модулей, актуальные версии спецификаций, зачётность и правила времени. Сборка учитывает компетенции, сложности, обе адаптивные ветки, форматы и историю показов. Новые вопросы во время прохождения не генерируются. Экспериментальные вопросы добавляются отдельно, по одной позиции при наличии в модуле; они не заменяют зачётную часть.

Запись пула в PostgreSQL выполняется только при отсутствии его ID. Одновременные запросы получают один сохранённый снимок. Изменения банка и спецификаций в течение дня применяются к будущим пулам, а не к текущему.

При старте сервер самостоятельно выбирает сегодняшний пул и фиксирует все модули, первую часть, обе возможные ветки второй части и кодинг. Ответы первой части определяют ветку, сохраняя прежнюю адаптивность. У каждого кандидата свой вариант по общей спецификации. Перезагрузка и повторный запрос запуска восстанавливают активную попытку.

Смена дня не закрывает начатую попытку, не меняет вопросы и не блокирует следующий модуль роли. Каждый открытый вопрос продолжает использовать собственный таймер. Новый тест использует новый пул дня.

Мейнтейнеры видят автоматически созданные суточные пулы в админке. Старые сессии, записи и результаты сохранены; прежние API записи/запуска по регистрации остаются для совместимости. Новый интерфейс не создаёт записи и запускается через `assessment-prepare` и `assessment-start` с `targetId`.
